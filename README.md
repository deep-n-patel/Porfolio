# Deep Patel — Software, Data & AI

Hey, I’m Deep. I'm a Computer Science honours student at the University of Manitoba.
I build apps, work with data, experiment with AI, and occasionally convince all
three to cooperate.

This is my little corner of the internet: projects, work experience, education,
and a few things I’m proud of. I gave it a game-inspired theme because apparently
a résumé wasn’t enough. It needed XP, collectibles, and a tiny version of me with
a laptop.

## What’s in here?

- **Things I’ve built:** Merginator, Finus, SafePath, Keep Me Alive, a chess game
  with an AI opponent, Chicago Crashes Database, and SpendSense. A reasonable
  mix of spreadsheets, finance, city data, and arguing with a chess algorithm.
- **Places I’ve learned:** the University of Manitoba, Richardson International,
  Marshalls and Homesense, Big Bang Events, hackathons, and Model United Nations.
  Some lessons involved SQL. Others involved talking to actual humans.
- **Things you can poke:** a clickable terminal, a tilting player card, and five
  hidden data shards. Collect them all to unlock a bonus fact. No account required;
  I’m already asking you to read about me.

## Press start

Open `index.html` in a modern browser. That’s enough to get going.

For a local server, run this from the project folder:

```powershell
npx serve .
```

It’s plain HTML, CSS, and JavaScript, with no build step. GSAP loads from a CDN
for the scroll animations. If it doesn’t show up, the content and core interactions
still work. The portfolio can survive a less dramatic entrance.

If you found all five shards first, feel free to lead with that. You’ve done your research.
